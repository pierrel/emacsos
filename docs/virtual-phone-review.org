full report, logs and captures remain private outside Git. Screenshots are

clarification are documentation-only; the tested runtime identities above

* Known boundaries

The guest has no external network, real credentials, personal history, modem,
sensors or battery. Assist is unavailable by design; real isolated Assist
integration remains roadmap work. Physical behavior is not established by guest
UI success. Mobile Firefox policy uses the native signed postmarketOS v25.06 package,
4.6.0-r0, via a one-off tagged repository. It matches the recorded physical
package input; no current physical package-version check is claimed. Its shipped
policy regenerates profile CSS and requests a Firefox restart on first use. A
development launch closed before an ordinary repeat launch displayed the mobile
browser UI; no automatic retry was added. This is separate from the blind run.

The guest has an unresolved historical SSH I/O-error observation;
no long-lived reliability guarantee follows from short acceptance sessions.

Physical shared deployment changes require source review and deterministic
