* Result

Implementation successor =56d2a2d5429b42a31aa9b2a3a5986a38b35e3cc8=,
tree =ccacb206c331ec20234603e090b23a4698223d59=, distinguishes a late
unconfirmed DELETE receipt from a retired observer.  When the exact resident
entry has already been revived by Refresh GET2 and owns the current stream,
the receipt reports its bounded status at thread level rather than replacing
the entry-owned assistant region.  Its partial live text and Abort action stay
intact, its state remains =observing=, and subsequent deltas remain valid.

When no observer owns that entry, the receipt retains the existing
entry-specific fixed status.  Confirmed cancellation, reload normalization,
aggregate surface release, and the resident-entry, Run, and cancellation
generation identity fences are unchanged.

The queue-backed regression uses a real GET2 observer start carrying partial
text and its Abort action, then exercises a DELETE transport error and
=running=, =transitioning=, and other unconfirmed outcomes.  It proves each
receipt preserves the body, action, observer ownership and state, and accepts
a later delta.
