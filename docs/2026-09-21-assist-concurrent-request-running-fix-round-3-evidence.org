* Round-three corrections

Dismiss now preserves its exact original FIFO and rendered regions if its cache
write fails.  Once durable, it removes only the dismissed region and action;
the follower regression activates its actual Dismiss button.  Abort/Detach
recomputes the aggregate surface after state transition on both durable and
failed-save paths.  Successful recovered-create Restore removes its action.
