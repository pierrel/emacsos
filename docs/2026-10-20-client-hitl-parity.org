when ordinary Run status is ready. Review fetches the bounded plural collection;

job state and explicit errors are visible before any actionable two-tap control.

fresh authoritative review, without automatically repeating an effect.

chooser. Empty refresh retires a vanished selection, including one selected while
GET was in flight. Malformed summary fields are rejected before rendering can
erase an unsent draft. Run receipts and independent acknowledgments remain
separate shapes; neither permits unrelated stop ownership to be discarded.
