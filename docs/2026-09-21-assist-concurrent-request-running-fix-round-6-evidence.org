* Round-six correction

The adoption, restored-cache, dismissal, and reconciliation paths all derive
collision from the same count rule: two or more resident entries remain a
recovery collision.  The mixed rejected/terminal regression proves that exact
reconciliation persists the retained rejected entry, removes only the terminal
entry, and reopens the recovered one-entry queue with its Dismiss action.

Entry action cleanup and retained-source recovery cleanup use the shared safe
range remover.  The legacy restore docstring now identifies that separate
nonqueue path rather than implying aggregate queue ownership.
