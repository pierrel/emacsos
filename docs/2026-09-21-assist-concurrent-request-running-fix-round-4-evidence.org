* Round-four corrections

Aggregate web activity now includes an in-flight legacy buffer only before that
buffer adopts entry ownership.  Entry and retained-source actions have explicit
ranges: reset, delta, status, redraw, terminal, interruption, and detach clear
only their actions before changing assistant text.  A recovered-head Restore
removes its action before its ready status, and the retained source Restore is
removed only after its cache save succeeds.

Queue admission validates the real endpoint body and a same-sized prospective
cache identity before minting an idempotency key.  The added bounds tests cover
the 64,000-character limit, actual create-body expansion, and a complete
over-512KiB prospective record.  The adoption overflow regression retains both
source and destination queues, tails, and cache ownership without a write.
