* Integration

The pinned wvkbd revision emits up to 24 glide letters and one balanced Space.
Its immediate plain Backspace is a one-shot retraction of that exact word-space
unit. An immediate explicit Space is coalesced with the emitted separator, and
ordinary punctuation replaces it. External focus, cursor, or hardware edits
cannot be observed. No Emacs integration or persistence is added. Keyboard
lifecycle and layout-context resets also disarm the one-shot undo.

The exact source pin is

correction recorded in wvkbd's =2026-09-11-glide-followup-spacing.org=.

* Live verification

The artifact was installed side by side as =/usr/local/bin/wvkbd-emacos=; the
stock package path was not replaced. On the running PinePhone, its SHA-256 was
the exact build hash above, =emacsos-ui= remained started, and the running
keyboard process used that path.

Synthetic touchscreen input against the real EmacsOS display verified these
visible results: gliding =test= produced =test= plus one separator; an immediate
Space left exactly that one separator; an immediate comma produced =test,=;
and one immediate Backspace returned the input to empty. A short upward swipe
on =a= still sent =C-a= and moved point to the start of visible =abc= text.
