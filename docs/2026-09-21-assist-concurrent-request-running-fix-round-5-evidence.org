* Round-five corrections

A buffer with an in-flight legacy request now refuses a same-buffer queue Send
without minting a key, rendering a region, changing its exact draft/point, or
releasing aggregate web activity.  Dismiss derives and persists collision from
the prospective remaining queue, restoring the original queue and collision on
write failure.  Entry and retained-source actions share one safe range remover.

The public POST matrix now distinguishes rejected 413/422/unavailable-harness
409 responses from retryable pending-approval 409.  The adoption tests cover a
destination cache write failure before source retirement and actual Dismiss
buttons contracting a four-entry collision while preserving source recovery and
destination editable tails.
