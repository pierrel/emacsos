* Status

This is the recovery implementation record for accepted design D5

It replaces the partial non-candidate implementation with durable per-entry
submission, observation, parser, cleanup, and recovery ownership.  Assist
remains the authority for Run FIFO and terminal truth; the client has no
long-lived global observer capacity.

* Recovery construction

Queue callers enter =--start-observation= and =--observe-entry=.  The latter
owns its exact entry key/epoch, process, response buffer, header timer, URL
completion callback, sentinel, and stock-filter wrapper.  Response callbacks
explicitly return to the owning thread buffer before consulting queue state.
Late, removed, adopted, killed, or stale-generation callbacks are inert.
Queue terminal, error, reset, delta, and status handling uses the captured
entry; the retained =--legacy-*= constructor/filter/cleanup chain is an
explicit nonqueue compatibility boundary.  Queue cleanup and reload never call
that chain.
