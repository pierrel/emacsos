catalog, so the native thread list could not replace its empty state.

points, U+200D and U+FE0F.  Bidirectional controls, every other Unicode format
control, and every other explicitly prohibited default-ignorable code point

identifiers.  Display text remains inside trusted bidirectional isolates;
collision grouping removes the two admitted zero-width marks before deriving
trusted client ordinals; row activation still resolves the validated opaque

It remains plain text and changes no action or modeline ordering.
