* Result

Implementation successor =2a70d52788fc45443883d839c29e592ad5cfd757=,
tree =ab6ce5dfc6851d37dc80fb3a2b1b4bfbd89a2d63=, normalizes an entry retained
through hot reload before it increments or compares its cancellation generation.
An older resident plist without that field receives generation zero in place,
so the captured DELETE target remains the resident entry.

On a matching confirmed =200/cancelled= receipt, the terminal transition now
recomputes aggregate web activity after stream retirement and before
reconciliation.  The revived stream therefore releases its web slot
immediately when it was the last transport, while another active web buffer
continues to hold that aggregate slot.  Dedicated resident-entry, exact-Run,
and cancellation-generation identity checks remain in force; error and
unconfirmed DELETE outcomes still permit Refresh progress.

The exact refreshed-observer regression now asserts both the real GET2 epoch
advance and immediate aggregate-slot release.  New coverage also verifies a
legacy retained entry without cancellation generation aborts successfully, and
that confirmed cancellation does not clear a peer web buffer's aggregate slot.
The stale-DELETE test description and setup now match the current identity
contract.
