=200/cancelled=.  Thus an Abort, a later Refresh GET, that confirmed DELETE,

the entry-owned failure path directly: it retains partial assistant text,
reports unverified observation status, returns the entry to
=accepted-unobserved=, and clears its raw-byte and suffix state.
