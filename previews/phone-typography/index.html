Start with Plex. Keep Inter close.

IBM Plex Sans + Mono is my first direction: spare, distinct, and at home in an Emacs phone. Inter + JetBrains Mono is the quieter alternative. Source Sans 3 + Source Code Pro is the reading-first choice. Compare at 18–20 logical pixels, regular prose, semibold headings, and 1.35–1.45 line height. This recommendation is a visual judgment; physical-screen rendering still needs a phone trial.

Chat preserves the current you>/bot> structure, editable > prompt, +15% Markdown headings, and fixed-pitch code. SMS uses the same role prefixes and status suffixes. Networks follows the seven-line chooser. The bottom mode line and external keyboard stay in place. Preview margins, palette, line spacing, and proportional non-chat UI are proposed styling, not a claim about the current theme.

The Droid card uses the same comparison sizes and spacing as the alternatives, so it isolates family choice. Current-phone face sizes and rendering are documented in the evidence notes. Code and terminals stay monospace. Ordinary UI can be proportional, but the existing character-cell button layout needs separate consideration before changing its font. The keyboard font stays Droid in these studies, to isolate Emacs typography.
