#+title: EmacsOS commands and keys

Use the on-screen =M-x= button, type a command name, then press =RET=.
The command list above the keyboard changes with the current buffer.  Its
buttons call the same Emacs commands listed here.

* Applications

| Action | M-x command |
|--------+-------------|
| Start or switch to Firefox | =emacsos-pinephone-open-firefox= |
| Quit Firefox started by EmacsOS | =emacsos-pinephone-quit-firefox= |
| Start or switch to Android | =emacsos-pinephone-open-waydroid= |
| Stop Android | =emacsos-pinephone-stop-waydroid= |

Use =Alt+Tab= to move between full-screen applications.  The on-screen =Chat=
button returns to the ordinary EmacsOS chat buffer; there it becomes =SEND=.

* Chat and messages

| Action | M-x command |
|--------+-------------|
| Return to ordinary chat | =emacos--chat-show-top-buffer= |
| Start a new ordinary chat | =emacos--chat-new-chat= |
| Stop the current ordinary-chat response | =emacos--chat-abort= |
| Open an Assist Web thread | =emacos-assist-web-open-thread= |
| Start an Assist Web thread | =emacos-assist-web-new-thread= |
| Send from an Assist Web thread | =emacos-assist-web-send= |
| Refresh an Assist Web thread | =emacos-assist-web-refresh-thread= |
| Refresh the Assist Web thread list | =emacos-assist-web-refresh-threads= |
| Load older Assist Web messages | =emacos-assist-web-load-older= |
| Stop an Assist Web response | =emacos-assist-web-abort= |
| Start a file-backed chat | =emacos-assist-new-file= |
| Forget a file-backed chat checkpoint | =emacos-assist-forget= |
| Compose an SMS | =emacos-send-message= |

Assist Web also uses the =C-c C-a= prefix:

| Key | Action |
|-----+--------|
| =C-c C-a t= | Open thread |
| =C-c C-a n= | New thread |
| =C-c C-a r= | Refresh thread list |
| =C-c C-a g= | Refresh current thread |
| =C-c C-a s= | Send |
| =C-c C-a o= | Load older messages |
| =C-c C-a a= | Abort response |

* Phone and network

|--------+-------------|
| Stage a call for confirmation | =emacos-call= |
| Answer the ringing call | =emacos-answer= |
| Hang up | =emacos-hang-up= |

The modeline network, call, SMS, and keyboard labels are touch controls for
their current status or action.

* On-screen command list

The command list changes with the buffer.  These labels are shortcuts to the
listed =M-x= commands.

=Dtach= (=dtach-shell=) is prepended to the ordinary-chat and fallback lists.
Ordinary chat changes =New chat= to =Confirm clear?= after the first tap and
shows =ROLLBACK= only when a configuration rollback is available.  The network
page shows state-dependent =Wifi on/off= and =Cell on/off= controls plus
=Refresh=.  Assist Web buffers deliberately show no parallel command list;
their commands use =M-x= or the =C-c C-a= prefix above.

* Files and terminals

| Action | Command or key |
|--------+----------------|
| Open a file | =M-x find-file= |
| Switch buffer | =M-x switch-to-buffer= |
| Save | =M-x save-buffer= |
| Undo | =M-x undo= |
| Open or choose a persistent terminal | =M-x dtach-shell= or =C-c d= |
| Reconnect the current persistent terminal | =M-x dtach-shell-reconnect= or =C-c S-d= |

* Hardware

| Control | Action |
|---------+--------|
| Power button | Blank the display; press again to wake |
| Volume button | Wake the display |
| =Alt+Tab= | Move to the next full-screen application |

When the custom modifier-swipe keyboard is active, swipe upward from a character
for =Control+character= and downward for =Meta+character=.
