#+title: EmacsOS commands and keys

Swipe downward from =x= on the modifier-swipe keyboard to type =Meta+x=, then
type a command name and press =RET=.  Run =M-x emacsos-open-command-reference=
to return to this file.

* PinePhone/OpenRC applications

These commands are installed only by the PinePhone/OpenRC deployment; the
generic =phone-install= target does not define them.

| Action | M-x command |
|--------+-------------|
| Start or switch to Firefox | =emacsos-firefox-start= |
| Quit Firefox started by EmacsOS | =emacsos-firefox-quit= |
| Start or switch to Android | =emacsos-android-start= |
| Stop Android | =emacsos-android-quit= |
| Hide or show the keyboard | =emacsos-pinephone-toggle-keyboard= |

Use =Alt+Tab= to move between full-screen applications.  Return to ordinary
chat with =M-x emacsos--chat-show-top-buffer=.

The global =C-c e= prefix works in every buffer.  On the touchscreen, swipe up
from =c= on the keyboard, then tap =e=, to type it.  =C-c C-a= remains the
contextual conversation prefix; its =n= and =t= leaves are retained globally
for canonical thread navigation.

| Key | Action |
|-----+--------|
| =C-c e c= | Ordinary chat |
| =C-c e t= | Open canonical thread |
| =C-c e n= | New canonical thread |
| =C-c e r= | Refresh thread list |
| =C-c e f= | New .assist file |
| =C-c e d= | Stage call |
| =C-c e m= | Stage SMS |
| =C-c e s= | Open SMS conversations |
| =C-c e w= | Network controls |
| =C-c e h= | This command reference |

** PinePhone/OpenRC-only bindings

These bindings are installed only by the PinePhone/OpenRC deployment;
the generic =phone-install= target does not define them.

| Key | Action |
|-----+--------|
| =C-c e k= | Hide or show the PinePhone keyboard |
| =C-c e b= | Start or switch to Firefox on PinePhone |
| =C-c e a= | Start or switch to Android on PinePhone |

** Conversation bindings

| Key | Action |
|-----+--------|
| =C-c C-a t= | Open thread |
| =C-c C-a n= | New canonical Assist thread |
| =C-c C-a g= | Refresh current conversation |
| =C-c C-a s= | Send |
| =C-c C-a a= | Abort or detach |
| =C-c C-a o= | Open the HTTP(S) object at point |
| =C-c C-a l= | Load older canonical history |
| =C-c C-a f= | Forget a file-backed conversation |

RET accepts an active minibuffer first.  Otherwise touchscreen RET invokes the
target buffer's physical =RET= binding: in a conversation it opens a literal
HTTP(S) object at point or inserts a newline, and in the native thread list it
opens the exact row at point.

* Phone and network

| Action | M-x command |
|--------+-------------|
| Stage a call for confirmation | =emacsos-call= |
| Answer the ringing call | =emacsos-answer= |
| Hang up | =emacsos-hang-up= |
| Open network controls | =emacsos-net-show= |
| Connect to a visible Wi-Fi network | =emacsos-net-connect= |
| Toggle Wi-Fi | =emacsos-net-toggle-wifi= |
| Toggle cellular data | =emacsos-net-toggle-cell= |

The modeline Threads, network, call, SMS, and keyboard labels are touch controls
for their current status or action.

An SMS conversation uses the compositor text keyboard with QUIT, Refresh, and
Send or ACK in its Emacs utility row.  Send still opens the separate two-tap
confirmation screen; ACK clears an indeterminate local send status.  Other
ordinary chat, editing, and Assist buffers have no separate Emacs control pane.

* PinePhone/OpenRC hardware

| Control | Action |
|---------+--------|
| Power button | Blank the display; press again to wake |
| Volume button | Wake the display |
| =Alt+Tab= | Move to the next full-screen application |

When the custom modifier-swipe keyboard is active, swipe upward from a character
for =Control+character= and downward for =Meta+character=.
